# Synapse-seq reveals cytotoxic CD4+ T cell suppression of human antibody responses

## Data availability

Study sequencing data have GEO accession [GSE351507](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE351507). Access depends on its release status. The auxiliary data archive contains 7,829 files and approximately 14.27 GB before compression. It is uploaded as 18 checksum-verified parts in the [data release](https://github.com/krkathuria/Synapse-seq_SpleenOrganoids_2026/releases/tag/doublets2-4-20261020). Download and extract the archive before running the analyses; a code clone alone does not include it. The accession should not be assumed to provide every auxiliary file. See [`DATA_DISTRIBUTION.md`](https://github.com/krkathuria/Synapse-seq_SpleenOrganoids_2026/blob/main/DATA_DISTRIBUTION.md).
