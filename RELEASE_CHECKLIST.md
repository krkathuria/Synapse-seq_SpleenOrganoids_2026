# Public release checklist

- [x] Create the private project repository and scientific README.
- [x] Collect an initial analysis snapshot with source provenance and checksums.
- [x] Remove stored notebook outputs and execution metadata.
- [ ] Confirm final figure-to-code mapping and remove unused exploratory branches.
- [ ] Reconcile dataset-specific QC descriptions with the final Methods.
- [ ] Add the complete upstream receptor/sequence-processing scripts and exact tool versions where available.
- [ ] Replace local paths with documented input/output configuration and complete the input manifest.
- [ ] Test installation and execution on documented example inputs; report expected outputs, time, and memory.
- [ ] Select the project license with the authors.
- [ ] Add the final paper citation and DOI to README and CITATION.cff.
- [ ] Publish a versioned release, archive it for a persistent identifier, and update the manuscript's code-availability statement.

The repository remains private until the authors are ready to release it.
